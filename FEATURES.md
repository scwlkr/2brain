# Features

- **Context reads:** `2brain` introduces Shane; tool/project selectors load relevant background. Wstack owns coding workflow.
- **Context editing:** CLI, VS Code, and OpenTUI edits save records with reversible Git history.
- **Context sync:** Exchange records through a user-owned Git remote; preserve conflicting versions for resolution.
- **Coding startup:** Codex loader activates installed Wstack unless the user opts out; extra context loads only when needed.
- **Brand export:** Save the bundled SVG artwork and brand guide to a new local directory.
